# ✂️ BarberBook — Sistema de Agendamento para Barbearias

Sistema de agendamento online para barbearias. O cliente agenda pelo celular em menos de 1 minuto, o barbeiro recebe no WhatsApp e o horário some automaticamente.

---

## 📁 Estrutura de arquivos

```
barberbook/
├── index.html              ← Landing page (pra postar no LinkedIn)
├── css/
│   └── style.css           ← Estilos globais
├── js/
│   └── supabase.js         ← Config do banco + helpers
└── pages/
    ├── cadastro.html       ← Cadastro da barbearia
    ├── login.html          ← Login
    ├── painel.html         ← Agenda do dia
    ├── servicos.html       ← Gerenciar serviços
    ├── horarios.html       ← Configurar horários
    ├── configuracoes.html  ← Dados da barbearia
    ├── agendar.html        ← Página do cliente (pública)
    └── confirmacao.html    ← Tela de sucesso
```

## 🔗 Demo ao vivo
👉 [Testar agora](https://helom17.github.io/BarberBook/pages/demo.html)

## O problema que resolve
Barbearias perdem vendas todos os dias porque o cliente manda
mensagem no WhatsApp, não recebe resposta rápida e agenda
em outro lugar. O BarberBook resolve isso com agendamento
online 24h, sem depender do barbeiro estar disponível.

## Funcionalidades
- Cadastro da barbearia com serviços, preços e duração
- Link único para compartilhar no Instagram e WhatsApp
- Cliente escolhe serviço, dia e horário disponível
- Horários ocupados somem automaticamente
- Notificação via WhatsApp para barbeiro e cliente
- Painel de agendamentos do dia e da semana
- 100% responsivo, funciona no celular sem instalar nada
